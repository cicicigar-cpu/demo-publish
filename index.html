SocialResearch Pro 使用手册

本手册说明如何使用 Agent Flow 发起一次完整的社媒专题分析：从选择场景、填写数据范围、输入分析需求，到检查工作流、运行报告和继续优化结果。

1. 产品概览：Agent Flow 适合做什么

聚合全量看板与 Agent Flow 面向不同使用场景，二者并非替代关系。聚合全量看板更适合用于灵活查数、筛选数据、查看明细和人工验证；Agent Flow 更适合用于承接一次完整的专题分析任务，系统可根据分析目标自动组织查数、内容归纳和报告洞察输出。

Agent Flow

适用于目标较明确、需要多步骤分析和结构化输出的专题任务。

典型用法：用户只需输入分析对象、对比对象、时间范围、平台范围和希望回答的问题，系统即可按照分析目标自动完成数据查询、内容归纳、阶段性判断和报告生成。

聚合全量看板

适合灵活筛选、查看明细、临时查数、手动验证数据。

典型用法：用户可以根据业务需要，自主选择分析对象、时间范围、平台和指标，查看声量、互动量、NSR 等数据表现，并进一步下钻查看原帖明细等。

2. 典型使用场景

场景一：商场竞品对标

对比本品商场和竞品商场在社媒上的声量、互动量、NSR、平台表现和高互动内容。

长宁来福士上海环球港上海龙之梦
典型问题：长宁来福士近 3 个月相比环球港、龙之梦，社媒表现处于什么位置？

场景二：商场口碑与消费场景

分析用户对单个商场的主要讨论内容、正负向口碑、消费场景和高传播内容类型。

餐饮展览拍照打卡亲子
典型问题：用户来长宁来福士主要讨论什么？哪些场景更容易带来互动？

场景三：趋势主题机会

围绕消费趋势或活动主题，判断其是否适合用于商场活动策划、招商方向或内容营销。

香氛情绪价值疗愈悦己消费
典型问题：“香氛 + 情绪价值”是否适合作为商场活动主题？

3. 使用旅程演示

使用主流程说明

1登录系统

使用数说账号进行登录即可。

  • 可使用聚合账户密码直接登录。
  • 如客户环境登录页不同，可在此处替换为客户环境截图。

2进入 Agent Flow

路径：进入首页后选择“智能体能力”，下拉至底部，选择 Agent Flow 进入。

  • Agent Flow 是用于发起自动化分析流程的入口。
  • 进入后可填写需求，生成研究报告。

3填写数据范围

选择本次分析需要覆盖的研究周期、社媒站点和数据范围。

  • 时间必须使用明确的日期，例如 2026年4月20日–2026年5月10日。
  • 平台范围应与本次分析问题一致，例如小红书、微博、抖音。

4输入分析需求

在任务输入区写清楚本次分析的对象、对比对象、时间范围、平台范围和希望回答的问题。

  • 不要写一句话的分析需求，效果会很差；尽量把分析描述清楚，例如需要分析什么大命题，以及大命题之下可以拆分成什么小角度的研究。
  • 如果数据范围在表单中无法筛选，也可以用自然语言补充说明，例如：数据范围使用 UGC 数据。
  • 任务难度选择自动即可，通常无需更改。
  • 一般从简单模式开始即可；如果选择详细模式，生成时间会更久一些。两种模式都可用，不会影响任务结果。

5生成并检查工作流

点击生成后，系统会根据分析需求自动拆解查询、处理和报告生成步骤。

  • 先看整体步骤是否符合业务逻辑。
  • 通常只需要检查数据查询节点和最终报告生成节点，重点确认目标和查询条件；其他节点一般不用处理。数据查询节点的检查方式会在后文展开说明。

6运行、查看报告并继续追问

确认工作流后点击运行。报告生成后，可在结果文件区预览或下载 HTML 文件，也可以通过对话助手继续补充分析。

  • 运行耗时会随任务复杂度和数据量变化，通常需要 40-60 分钟。
  • HTML 可以下载到本地文件后双击打开，通常会默认用浏览器打开；如打不开，请检查文件后缀是否为 .html。
  • 后续可以通过对话助手，对报告结果进行小范围的改写或者样式优化。

7导入与导出工作流

完成配置后的工作流可以导出保存，后续需要复用时再导入修改和重跑。

  • 适合将常用分析流程沉淀为可复用模板。
  • 复用时建议重新检查分析对象、时间范围、平台范围和关键词。

4. 工作流生成后如何检查

工作流生成后，不需要查看每一个节点，只需要关注数据查询节点和最终的报告生成节点，重点确认目标、步骤和查询条件是否符合业务需求。

1检查节点大目标是否正确

先打开关键数据查询节点，查看节点里的 Goal 是否说明要查询什么数据、如何整理，并供最后的报告生成使用。

  • 如果大目标偏了，建议先修改目标；这里不需要出现具体的报告撰写要求。
  • 该示意图中，只有目标 Goal 信息是重要的，其他配置项无需关注。

2生成 AI 详细计划，检查小目标

切换编辑模式，并点击 AI 生成计划，查看计划中的小目标是否覆盖了要回答的问题。

  • 这里重点关注编辑模式后的内容，其他配置项无需关注。
  • 重点看步骤顺序是否大致合理：先确认对象和范围，再查询数据，最后归纳内容并生成报告。
  • AI 生成计划后，会自主地规划步骤和选择对应的查询工具；查询工具通常不会出错，更重要的是关注每个步骤中的小目标是否偏离任务目的；如果偏离，可以修改。

3检查工具参数是否合理

进入工具设置页面，点击 AI 自动生成参数，重点查看关键词、过滤词、时间范围、平台范围和排序方式是否正确。

  • 如果需要取原帖，特别注意原帖数量是否过多；通常 Top 100 条足够支撑分析。
  • 参数确认后可以点击试调用，并拉到底部查看是否调用成功。

4检查报告结果节点目标

最后查看报告生成节点，确认报告目标是否符合本次分析需求。

  • 重点看报告要回答的问题、输出结构和分析重点是否准确。
  • 如果报告目标偏离需求，可以先修改该节点目标，再重新生成或运行。

5. 如何写好分析需求

Agent Flow 的生成质量，主要取决于分析需求是否清楚。切记，一句话需求生成的 Agent Flow 效果通常会比较差。

探索性需求 Prompt 写法

明确分析目的，但没有严格的报告图表结构要求，希望更多让 AI 自由发挥。

探索性需求 Prompt 示例 
请分析 2026 年五一期间长宁来福士在社媒上的表现，并对比上海环球港、上海龙之梦。

我希望了解：
1. 三家商场谁的声量、互动量和口碑表现更好；
2. 长宁来福士相比竞品有哪些传播优势和短板；
3. 用户主要在夸什么、吐槽什么；
4. 哪些高互动内容值得长宁来福士后续借鉴；
5. 给出内容营销和运营优化建议。

数据范围：
- 时间：2026年4月20日–2026年5月10日
- 平台：小红书、微博、抖音
- 指标：声量、互动量、NSR、Top N 原帖

注意事项：
- 允许你看着补充。

结构性需求 Prompt 写法

明确分析目的，且每个章节的小命题、报告图表结构有严格要求，可以细化需求描述，支撑 AI 的产出更接近期望结果。

结构性需求 Prompt 示例 
# 长宁来福士五一期间社媒表现与竞品对标分析 Prompt

## 分析任务

请分析 **2026 年五一期间长宁来福士在社媒上的表现**，并对比 **上海环球港、上海龙之梦**，判断长宁来福士在同城商业体竞争中的社媒表现位置、内容传播优势、用户口碑表现和后续运营优化方向。

## 分析对象与数据范围

- **本品商场**：长宁来福士
- **对比对象**：上海环球港、上海龙之梦
- **时间范围**：2026年4月20日–2026年5月10日
- **平台范围**：小红书、微博、抖音
- **重点指标**：声量、互动量、NSR、平台分布、Top N 原帖、用户评论
- **输出目标**：生成一份面向凯德国际商场运营、内容营销及项目管理团队的社媒表现分析报告

---

# 报告结构要求

## 摘要

请用 2–3 段总结本次分析的核心发现，包括长宁来福士相较竞品的整体位置、主要优势、主要短板和后续建议方向。

---

## 第一章 长宁来福士社媒表现概览

### 1.1 平台声量与互动量分布

分析长宁来福士在小红书、微博、抖音三个平台上的声量和互动量分布，判断哪个平台贡献了主要声量，哪个平台贡献了主要互动。

**图表要求**：输出一张平台声量与互动量分布图，可使用双饼图、堆叠柱状图或分组柱状图。

### 1.2 长宁来福士 NSR 趋势分析

分析长宁来福士在三个平台上的 NSR 表现，判断整体口碑是否稳定，是否存在明显负面波动日期。

**图表要求**：输出一张各平台每日 NSR 趋势折线图，并标注明显异常点。

---

## 第二章 竞品对标分析

### 2.1 三家商场核心指标对比

对比长宁来福士、上海环球港、上海龙之梦的总声量、总互动量和各平台 NSR，判断长宁来福士在三家商场中的整体位置。

**图表要求**：输出一张三家商场核心指标对比表，并配合声量/互动量对比柱状图。

### 2.2 各平台声量与互动量差异分析

对比三家商场在小红书、微博、抖音三个平台上的声量和互动量，判断各商场的平台优势和传播结构差异。

**图表要求**：输出两张分组柱状图，分别展示三家商场在各平台的声量对比和互动量对比。

### 2.3 各平台 NSR 口碑差异分析

对比三家商场在小红书、微博、抖音上的平均 NSR，判断哪家商场口碑更稳，长宁来福士是否存在平台口碑短板。

**图表要求**：输出一张三家商场各平台平均 NSR 对比柱状图。

---

## 第三章 传播优劣势诊断与用户舆情洞察

### 3.1 长宁来福士传播优势与短板总结

基于前文数据，总结长宁来福士的核心传播优势和主要短板，每条判断都需要对应数据或内容证据。

**图表要求**：输出一组“优势 / 短板”对照卡片或结构化表格。

### 3.2 用户好评维度分析

基于用户评论和高互动内容，归纳用户对长宁来福士的主要好评方向，例如活动体验、空间氛围、历史建筑、餐饮服务、打卡体验等。

**图表要求**：输出一张好评关键词词云或好评主题分类图，并列举代表性评论。

### 3.3 用户差评与体验短板分析

基于用户负面评论和相关原帖，归纳长宁来福士的主要吐槽点，例如餐饮品质、活动规则、拥挤排队、停车动线、活动覆盖范围等。

**图表要求**：输出一张差评关键词词云或吐槽主题分类图，并列举代表性评论。

### 3.4 舆情波动原因分析

分析 NSR 出现明显波动的日期，结合评论和原帖判断波动可能由什么内容或事件引发；若评论量较少，需要说明样本限制。

**图表要求**：输出一张异常日期说明表，包含日期、平台、NSR 表现、可能原因和代表内容。

---

## 第四章 高互动内容创意与传播模式拆解

### 4.1 长宁来福士 Top 高互动内容分析

提取长宁来福士在各平台的 Top N 高互动原帖，分析这些内容的主题、形式、账号类型和高互动原因。

**图表要求**：输出一张 Top 原帖列表，并可配合 Top 原帖互动量横向柱状图。

### 4.2 竞品 Top 高互动内容对比

对比上海环球港、上海龙之梦的高互动内容，识别竞品哪些内容类型、活动主题或传播方式值得长宁来福士参考。

**图表要求**：输出一张三家商场 Top 内容对比表，说明各自高互动内容的出圈原因。

### 4.3 可借鉴的内容传播模式

总结五一期间更容易获得传播的内容模式，例如快闪活动、IP 联名、美陈打卡、明星粉丝、历史建筑叙事、亲子体验等。

**图表要求**：输出一张“传播模式—代表内容—适用场景—可借鉴点”的表格。

---

## 第五章 营销策略建议与优化方案

### 5.1 内容营销方向建议

结合平台表现和高互动内容，给出长宁来福士后续在小红书、微博、抖音上的内容营销建议。

**图表要求**：输出一张平台运营建议表，分别说明每个平台适合强化的内容类型和原因。

### 5.2 商场运营服务优化线索

结合用户吐槽和竞品对比，提出长宁来福士在商户管理、活动机制、停车动线、服务体验等方面可关注的优化线索。

**图表要求**：输出一张运营优化建议表，区分“内容运营可改善的问题”和“需要线下运营改善的问题”。

---

## 第六章 总结与展望

请总结长宁来福士在五一期间的整体表现，明确其在同城竞品中的核心位置，并给出下一阶段最值得优先推进的 3 条行动建议。

---

# 写作要求

- 每一章先给结论，再给数据和内容证据。
- 不要只罗列数据，需要解释数据背后的业务含义。
- 所有关键判断都要尽量对应声量、互动量、NSR、Top 原帖或用户评论证据。
- 不要把社媒热度直接等同于线下客流、销售额或招商效果。
- 如果某个平台或某类评论样本量不足，需要明确说明。
- 建议要具体到平台、内容主题或运营动作，避免写“加强运营”“提升传播”等空泛表达。

分析需求编写小结

先说明你要分析什么

写清分析对象、对比对象和研究时间，例如“2026 年五一期间长宁来福士 vs 上海环球港、上海龙之梦”。

再说明你想回答什么问题

例如谁的传播表现更好、用户主要夸什么和吐槽什么、哪些内容值得借鉴、后续应该怎么优化。

最后说明你希望如何输出

如果对报告结构、章节小命题或图表有明确要求，可以直接写出来，系统会更容易生成符合预期的工作流和报告。

6. 数据能力说明

这里的“智能体”可以理解为系统自动调用的数据能力。不需要记住底层工具名，只需要知道它能支持哪些分析。

聚合智能体能力

查询指定关键词的整体表现

查询指定关键词在指定社媒平台上的声量、互动量和 NSR 表现。

声量互动量NSR

查询社媒指标趋势

查看相关社媒指标在指定时间范围内的变化趋势，用于识别峰值、波动和阶段差异。

趋势峰值波动

查询 Top N 原帖

通常建议取互动量 Top 100 原帖进行分析，既满足分析需求，也不会消耗过多 token；可在详细计划中点开具体参数配置进行调整。

高互动原帖代表内容

查询原帖评论数据

查询相关原帖下的评论数据，用于进一步理解用户反馈、好评方向和负面体验。

用户评论口碑线索

网络搜索智能体

网络搜索智能体可以用于补充公开资料、活动背景、品牌信息或行业趋势，但需要鉴别数据来源的可信度。涉及关键结论时，仍建议回到聚合数据、原帖或评论证据进行复核。

使用建议：如果是严谨报告，请谨慎使用该智能体，并仔细核查数据来源是否真实。

7. Agent Flow 使用注意事项

在 Agent Flow 过程中，以下三点会明显影响工作流质量和最终报告可用性。

分析需求要尽量清晰 Prompt 写清楚分析对象、时间范围、平台范围和希望回答的问题，生成的工作流改动会少很多。
重点关注步骤目标 明确查询步骤是否大致符合业务逻辑，并查看关键词、过滤词等重点参数是否符合自身需求。
不用一次完美 初版报告出来后，可以继续追问，对可视化、某个论点的文案或报告样式做小范围优化。

8. 能力边界与常见问题

Agent Flow 可以提升社媒分析效率，但仍依赖底层数据、关键词配置和标签质量。以下边界建议在正式使用前先了解。

适合回答

  • 某个商场在社媒上的声量和互动表现如何。
  • 与竞品商场相比，当前处于什么位置。
  • 用户主要讨论哪些内容、场景和口碑点。
  • 某个趋势主题是否适合做活动策划或内容营销方向。

不直接回答

  • 商场真实客流变化。
  • 门店销售额、租金收益和招商转化。
  • 会员消费、交易数据和线下 ROI。
  • 未开通数据源或未配置对象的表现。

常见问题

需要自己从零搭建 Agent Flow 吗？

建议尽量一次性写清楚分析需求。需求足够清楚的情况下，Agent Flow 生成的节点流一般不需要再做修改。

Agent Flow 和聚合全量看板有什么区别？

看板适合灵活查数和查看明细；Agent Flow 适合承接目标明确、需要多步骤分析和结构化输出的专题任务。

如果结果不准，应该先改哪里？

优先检查分析对象、关键词、过滤词、时间范围和平台范围。多数结果偏差来自对象召回不准或关键词边界不清。

可以直接用结果判断线下客流或销售变化吗？

不建议。Agent Flow 结果基于社媒数据，适合判断线上讨论热度、内容传播和口碑线索，不直接代表线下客流、销售额或招商转化。
