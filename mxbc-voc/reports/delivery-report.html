01 / 管理层摘要

核心判断与治理方向

报告不止罗列问题，而是把问题体量、用户原声、可能根因和治理动作串成证据链。

根因属于基于标签、关键词和评论文本的可能归因，不作为已验证因果事实。
01

第一阶段先修高频、可控问题

缺物料 933 条、备注未执行 704 条，均属于门店或门店+系统可快速治理的问题。

02

产品体验的核心是稳定性

份量少、口味不合预期、水感重和状态异常共同指向制作标准、配比、量具与到手状态的不稳定。

03

低频高伤害问题需单独预警

异物问题 94 条，强负向占比高，不应仅按问题体量进入普通排序。

核心计算公式
  • 标签覆盖率 = 非空标签评论数 / 总评论数。
  • 负向占比 = 情感极性为负向的评论数 / 总评论数。
  • 强负向占比 = 情感强度为强负向的评论数 / 总评论数或对应问题评论数。
  • 问题率 = 该区域某标签评论数 / 该区域有标签评论数。
  • 强负向率 = 该区域强负向评论数 / 该区域评论数。
  • 区域集中度 = 该区域某问题占该问题全国总量的比例。
  • 区域风险指数 = 标准化问题率 * 0.4 + 标准化强负向率 * 0.35 + 标准化集中度 * 0.25。
  • 行动优先级总分 = 问题体量 * 35% + 情绪强度 * 30% + 可控性 * 20% + 区域集中度 * 15%。
